Case study: Marketing Automation Pipeline

Four coordinated agents turned a manual lead processing workflow into an automated pipeline — 2,400+ leads/month.

Lead Scoring Agent

Evaluates each lead against intent signals, firmographic fit, and engagement history — producing a 0–100 confidence score that prioritizes sales attention.

Data Enrichment Agent

For high-confidence leads, retrieves account context — recent funding, tech stack, news — from public APIs and updates the CRM before a rep touches the record.

Smart Sequence Agent

Generates personalized outreach sequences per lead profile, selecting channel, timing, and message variant from approved templates — then A/B tests.

Outcome Analytics Agent

Attribution agent tracking every step — opens, replies, meetings booked — feeding results back into scoring weights and sequence logic.

Built on LangGraph for agent orchestration, Pinecone for lead profile retrieval, FastAPI for the service layer, and a React dashboard for operator oversight — with human-in-the-loop approval on outbound messaging.
